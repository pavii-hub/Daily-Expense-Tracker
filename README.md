# Daily Expense Tracker

A Python-based application to manage and track daily expenses.
## Project Description

The Daily Expense Tracker is a Python-based application
designed to help users manage and monitor their daily expenses.

Users can add, view, search, and delete expenses.
The application also provides category-wise summaries,
monthly expense reports, and monthly budget tracking.

## Features

- Add new expenses
- View all recorded expenses
- Calculate total expenses
- Category-wise expense summary
- Monthly expense summary
- Delete expenses
- Search expenses
- Monthly budget tracking
- Store expense records using JSON

## Technologies Used

- Python
- JSON
- Visual Studio Code
- GitHub

## How to Run

1. Install Python.
2. Download this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run:

   py expense_tracker.py
